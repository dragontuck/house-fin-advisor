## What is House Financial Advisor?

**House Financial Advisor** is a privacy-first, self-hosted household financial intelligence platform. It helps two-person households understand their financial state, plan budgets, track goals, and receive AI-driven financial guidance—without sending sensitive financial data to external servers.

**Core Value Proposition**: Your household financial data stays in your home. Your AI advisor stays in your home. Your financial calculations are deterministic, auditable, and explainable.

---

## Market Problem

### The Privacy-Finance Dilemma
- **Current state**: Households using financial apps send sensitive data to cloud platforms daily
  - Bank balances, transaction histories, credit card statements
  - Utility bills, loan terms, investment accounts
  - Income, spending patterns, family financial goals
- **Risk**: Data breaches, third-party monetization, regulatory exposure
- **Existing solutions**: All mainstream personal finance apps (Mint, YNAB, Personal Capital) use cloud-based models requiring data sharing

### The AI-Finance Accuracy Problem
- **Current state**: AI-driven financial advice is often unreliable
  - LLMs hallucinate balances and rates
  - Recommendations lack audit trails
  - No explanation of assumptions or evidence
  - Users cannot verify calculations or challenge recommendations
- **Existing solutions**: None—most fintech apps simply don't use AI for recommendations

### Target Market
- **Primary**: Privacy-conscious households (20M+ in US, growing due to data breach awareness)
- **Secondary**: Households seeking explainable, auditable financial advice
- **Tertiary**: Self-hosting advocates and enterprises managing employee financial wellness

## Security & Privacy Model

### Privacy Guarantees
- ✅ **Zero External Exposure** by default: All financial data remains on your server
- ✅ **Privacy Gateway**: External AI calls are filtered to remove identifiers (SSN, account numbers, routing numbers, card numbers, raw statements)
- ✅ **Tool-Only AI Access**: LLM cannot access raw database, filesystem, shell, or network
- ✅ **Append-Only Transactions**: Once recorded, transactions cannot be silently modified
- ✅ **Audit Trail**: Every financial state change is logged with timestamp, user, and evidence

### Security Architecture
- **Authentication**: OAuth 2.0 via Keycloak (enterprise-grade)
- **Authorization**: Role-based (household owner vs. member)
- **Data Encryption**: TLS in transit; encryption at rest optional (self-hosted choice)
- **SQL Injection Prevention**: Parameterized queries, ORM-based data access
- **CSRF Protection**: Standard web application security patterns
- **API Rate Limiting**: Per-user, per-endpoint protection
- **Session Management**: Secure tokens, configurable timeout

### Compliance Ready
- **GDPR**: Data residency control, export/deletion workflows
- **PCI-DSS Guidance**: No card storage; references only
- **SOC 2 Ready**: Audit-trail framework in place
- **CCPA**: Consumer data control and portability

## Technical Depth

### Architecture
- **Modular Monolith**: Clear service boundaries (household, accounts, budgets, goals, recommendations)
- **Framework**: Node.js + Express (API), React 18 + TypeScript (UI)
- **Database**: PostgreSQL (self-hosted)
- **Cache**: Redis (self-hosted)
- **Auth**: Keycloak (self-hosted)
- **Deployment**: Docker Compose (single `docker-compose.yml` to start)

### Financial Calculations
- **Money Representation**: Integer cents (no floating-point errors)
- **Deterministic Engine**: All calculations are testable, reproducible, and auditable
- **Test Coverage**: Financial domain has 90%+ test coverage
- **Validation Layer**: Independent validator checks all recommendations before delivery

### AI Integration
- **Provider**: Anthropic Claude (currently; extensible to other models)
- **Safety**: All tool calls are logged, typed, and validated
- **Reasoning**: Chain-of-thought planning with explicit tool selection
- **Explainability**: Every recommendation includes question, context, tools used, and evidence

## Business Model & Deployment

### Deployment Options

**Option 1: Self-Hosted (Default)**
- Household runs Docker Compose on their own server or home lab
- All data stays local, no monthly fees
- Requires: Docker, ~2GB RAM, 20GB storage

**Option 2: Managed Hosting** (Future)
- Provider hosts encrypted containers; household controls encryption keys
- Zero-knowledge architecture (provider cannot see financial data)
- $X/month for hosting

**Option 3: Enterprise Deployment** (Future)
- Corporate wellness platform using House Advisor
- Multi-employee household data segregation
- SAML/LDAP integration for enterprise auth

### Revenue Model

**B2C (Direct Households)**
- Freemium: Self-hosted version (no fees)
- Premium: Optional managed hosting or enhanced features

**B2B (Enterprises/Partners)**
- OEM licensing for employee financial wellness platforms
- White-label deployment with partner branding
- Integration fees for financial institution partners

**B2B2C (Insurance/Fintech Partners)**
- Embed as a feature in existing apps
- Revenue share on user retention
