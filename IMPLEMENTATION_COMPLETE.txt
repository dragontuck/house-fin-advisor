🎓 KEY LEARNING POINTS
═══════════════════════════════════════════════════════════════════════════════

1. Money Type Pattern
   • Use branded types for precision: Money = number & { __brand: "Money" }
   • Store as integer cents to avoid floating-point errors
   • Provide conversion helpers (MoneyFromDollars, MoneyToDollars)

2. Determinism in Finance
   • Identical inputs must produce identical outputs
   • No random elements or external dependencies
   • Critical for reproducibility and auditing

3. Error Handling Strategy
   • Fail fast on invalid data (throw immediately)
   • Never silently skip unsupported types
   • Provide clear, actionable error messages

4. Account Classification
   • Organize by type and purpose (asset, liability, etc.)
   • Filter by status (active only)
   • Calculate appropriate metrics for each category

5. Health Status Assessment
   • Multi-factor evaluation (net worth, cash flow, debt ratio)
   • Three clear levels for user understanding
   • Based on stability and financial position
